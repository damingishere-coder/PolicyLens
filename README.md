# PolicyLens

PolicyLens 是一个面向 Windows 的本地优先保险研究与家庭保单管理工具。它把中国内地、香港及宠物保险资料整理为可追溯的数据，提供同口径比较、养老现金流测算、证据核验与年度复盘。

> 当前状态：产品边界与 V1 UI 已确认，仓库处于开发文档阶段，尚未提供可安装程序。

## 核心原则

- **本地优先**：真实家庭资料、电子保单、健康信息和本地数据库不进入 GitHub。
- **证据优先**：结论必须能回到正式条款、利益演示书、监管披露或官方页面的具体位置。
- **保证与非保证分离**：合同保证利益、演示利益、历史实现率和 AI 推断不得混为一谈。
- **计算可复核**：现金流、IRR、回本年龄和汇率情景由确定性代码计算，AI 只负责解释与提出核验问题。
- **人工最终确认**：OCR、规则提取和 Codex 输出都是草稿，不自动变成已核验事实。
- **不代替专业意见**：本项目不提供投保、投资、税务、法律、承保或理赔结论。

## V1 范围

V1 实现家庭保单档案、内地产品库、香港产品库、宠物险产品库、证据中心、导入核验、同口径比较、养老规划、复盘提醒和可选的 Codex CLI 分析。车险、企业险等全市场险种只保留扩展入口，不在 V1 建立完整业务逻辑。

## 隐私提醒

仓库只能包含源代码、公开资料索引和合成测试数据。请勿提交真实姓名、证件号、联系方式、完整保单号、健康资料、原始保单、计划书、数据库、密钥、Cookie、日志或私人导出报告。
