# PolicyLens

PolicyLens 是面向普通家庭的 Windows 本地保险档案与规划工具。先记下自己和家人的保险，再整理缴费、资料、待办和养老目标；需要挑选产品时，使用保存条件的比较、可追溯证据与逐次确认的 AI 解读。

> V2 家庭工作区：采用浏览器访问本机服务，由已有 RunDock 项目托管。六个主入口为家庭首页、我的家庭、我的保单、挑选与比较、养老规划、资料与笔记；香港公开研究作为高级工具保留。

## 核心原则

- **本地优先**：真实家庭资料、电子保单、健康信息和本地数据库不进入 GitHub。
- **证据优先**：结论必须能回到正式条款、利益演示书、监管披露或官方页面的具体位置。
- **保证与非保证分离**：合同保证利益、演示利益、历史实现率和 AI 推断不得混为一谈。
- **计算可复核**：当前基础养老月度收支由确定性代码计算，保存输入与结果快照；IRR、通胀、汇率等复杂情景尚未实现。AI 只负责解释与提出核验问题。
- **人工最终确认**：OCR、规则提取和 Codex 输出都是草稿，不自动变成已核验事实。
- **不代替专业意见**：本项目不提供投保、投资、税务、法律、承保或理赔结论。

## 当前可用范围

当前实现包括：研究环境准备度检查、公开研究预览与逐次确认、三家公司逐项结果、官方域名和 SSRF 安全门禁、HTML/PDF 原文加密归档、证据摘录逐字匹配、未核验候选即时浏览与 2–4 候选并排比较、人工字段核验、正式产品证据矩阵、本地产品/候选/来源搜索、家庭保单、Codex 比较草稿及跨机器加密备份。

V2 新增独立成员与多保单关联、无产品前置条件的草稿建档、个人约定、保障期间、多期应缴与实缴、按年度与原币统计、站内待办、关联保单的加密 PDF 原件、比较条件与历史快照、多成员养老目标和三种收入情景、可复算快照及受控的保单／养老解读。所有涉及家庭内容的新记录存放在加密字段中；未登记信息不表示没有保障，AI 笔记不修改事实核验状态。

当前不会自动购买、投保、联系保险公司或把 AI 输出当成事实。第三方页面只保留为线索。图片 OCR、系统通知、复杂养老现金流、内地产品主动研究暂未实现；扫描 PDF 可先加密存档和查看原件。站内待办不承诺应用关闭后发送通知。自动化验证使用合成家庭资料和假 Codex，不消耗真实 AI 用量；实际研究和解读仍需在页面逐次检查外发预览并确认。

当前本机开发运行入口为 `http://127.0.0.1:8768`。React 页面与 FastAPI API 使用同一 Origin，RunDock 负责服务启动、自动重启、端口参数和进程状态；浏览器只是访问界面，不持有本地文件系统或命令执行权限。

## 隐私提醒

仓库只能包含源代码、公开资料索引和合成测试数据。请勿提交真实姓名、证件号、联系方式、完整保单号、健康资料、原始保单、计划书、数据库、密钥、Cookie、日志或私人导出报告。
