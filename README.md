# PolicyLens

PolicyLens 是一个面向 Windows 的本地优先保险研究与家庭保单管理工具。当前产品主线是香港储蓄保险与年金：通过用户逐次确认的 Codex CLI 实时网页搜索发现公开线索，只抓取预置保险公司官方域名，把证据匹配后的字段交给用户核验，再进入本地产品档案和同口径对比。

> 当前状态：主动研究第一版先覆盖友邦香港、保诚香港和宏利香港；采用浏览器访问 `http://localhost:<端口>`，本地服务由 RunDock 托管，不提供桌面安装包。未完成模块统一放在“规划中”。

## 核心原则

- **本地优先**：真实家庭资料、电子保单、健康信息和本地数据库不进入 GitHub。
- **证据优先**：结论必须能回到正式条款、利益演示书、监管披露或官方页面的具体位置。
- **保证与非保证分离**：合同保证利益、演示利益、历史实现率和 AI 推断不得混为一谈。
- **计算可复核**：现金流、IRR、回本年龄和汇率情景由确定性代码计算，AI 只负责解释与提出核验问题。
- **人工最终确认**：OCR、规则提取和 Codex 输出都是草稿，不自动变成已核验事实。
- **不代替专业意见**：本项目不提供投保、投资、税务、法律、承保或理赔结论。

## 当前可用范围

当前实现包括：研究环境准备度检查、公开研究预览与逐次确认、三家公司逐项结果、官方域名和 SSRF 安全门禁、HTML/PDF 原文加密归档、证据摘录逐字匹配、未核验候选即时浏览与 2–4 候选并排比较、人工字段核验、正式产品证据矩阵、本地产品/候选/来源搜索、家庭保单、Codex 比较草稿及跨机器加密备份。

当前不会自动购买、投保、联系保险公司或把 AI 输出当成事实。第三方页面只保留为线索；养老现金流、图片 OCR、提醒、内地产品主动研究和其他险种仍在“规划中”。自动化测试全部使用合成资料和假网络，不访问真实官网；第一次真实研究仍需用户在页面查看用量提示并手动确认。

当前本机开发运行入口为 `http://127.0.0.1:8768`。React 页面与 FastAPI API 使用同一 Origin，RunDock 负责服务启动、自动重启、端口参数和进程状态；浏览器只是访问界面，不持有本地文件系统或命令执行权限。

## 隐私提醒

仓库只能包含源代码、公开资料索引和合成测试数据。请勿提交真实姓名、证件号、联系方式、完整保单号、健康资料、原始保单、计划书、数据库、密钥、Cookie、日志或私人导出报告。
