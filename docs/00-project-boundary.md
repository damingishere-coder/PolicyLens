# 项目边界

## 产品定位

PolicyLens 是供一个家庭在 Windows 本地使用的保险资料研究、结构化比较和保单复盘工具。源代码公开，真实家庭资料永远留在用户控制的本地私有存储中。

平台输出的是“可追溯的研究材料”，不是销售推荐或代办服务。所有关键结论都应回答三个问题：数据来自哪里、何时有效、哪些仍不确定。

## V1 必做范围

- 家庭成员与保单档案，包含自费险、团险、赠险及待核实记录的分类。
- 中国内地保险产品资料库。
- 香港保险产品资料库。
- 宠物保险资料库和比较模板。
- 本地 PDF、图片、表格及手工资料导入。
- 字段级证据、版本、核验状态及冲突处理。
- 同口径产品比较，强制展示假设和不可比项。
- 养老现金流、保证/非保证利益、IRR、回本与汇率情景计算。
- 年度复盘、到期提醒和待办事项。
- 用户主动触发的 Codex CLI 解释与研究草稿。
- Markdown、CSV 和适合打印的本地报告导出。

上述内容是完整 V1 产品范围，不要求在第一次可用交付中一次完成。

## 首次可用交付

首次交付只实现一条可安装、可恢复的最小闭环：

1. 建立本地工作区、最小 Dashboard、家庭成员与保单档案。
2. 手工录入或导入可提取文本的 PDF，生成候选字段和证据锚点。
3. 人工核验字段，保留来源权威性、值来源和核验状态。
4. 选择两个本地产品版本做基础字段比较，不包含 XIRR、养老或汇率模型。
5. 用户预览白名单脱敏数据后，主动生成 Codex 研究草稿。
6. 使用恢复密码创建手工加密备份，并能在另一台 Windows 电脑恢复。

当前主动研究增量在首次交付基础上增加香港储蓄/年金官网采集，先覆盖友邦、保诚、宏利，并保留逐次确认、官方域名白名单和人工核验门禁。图片 OCR、Excel 导入、内地/宠物产品主动研究、养老计算、复盘提醒和批量报告导出仍属于后续增量。

## V1 只留入口

车险、企业险、责任险、货运险等全市场险种统一收纳到“规划中”，不占据核心导航，也不建设专用计算、爬取或推荐逻辑。

## 明确不做

- 自动投保、支付、退保、保全、理赔申请或联系保险销售人员。
- 承保概率、疾病诊断、理赔必然性或个体适配性的确定性判断。
- 把 AI、搜索摘要、销售话术或历史分红当作合同事实。
- 绕过登录、验证码、付费墙、WAF、robots 或网站访问条款。
- 自动把真实家庭数据发送到 GitHub、遥测服务、崩溃收集平台或第三方模型。
- 以一个综合分数掩盖司法辖区、币种、保障责任和现金流的不可比差异。

## 市场边界

内地和香港共用一套基础产品、利益、现金流和证据模型，但采用不同的市场适配器。每条记录必须保留司法辖区、合同币种、监管/发行主体、条款版本和适用地区。

跨市场页面可以并列展示，但只有在被保险条件、预算、缴费期、领取起点、保证口径和汇率假设一致时，才允许输出对比指标。税务、跨境服务、理赔路径和法律适用范围只能作为风险提示，不能由平台下结论。

## 决策权限

- 确定性代码负责金额、日期、现金流和公式计算。
- 规则引擎负责缺失字段、冲突、过期和比较资格检查。
- Codex 负责解释差异、总结证据和生成待核实问题。
- 用户负责核验原文、调整假设以及最终购买或保单操作决策。

## 成功定义

V1 成功不以“收录产品最多”为标准，而以以下结果衡量：家庭资料不会泄露；关键事实可回到原文；未知项不会伪装成事实；同口径计算可复现；应用离线仍可完成主要档案和测算工作。
