# 产品需求

## 目标用户与使用方式

首版只有一个本地家庭工作区，不提供账号注册、多人云同步或公共分享。家庭成员可以作为数据对象存在，但程序默认由 Windows 当前用户操作。

## 首次交付定义

首次交付是可安装的 Windows 本地应用，不是 14 个页面全部完成。它必须跑通“导入两份合成产品资料 → 提取候选字段 → 人工核验 → 查看字段证据 → 基础比较 → 预览脱敏数据 → 生成 Codex 草稿”的闭环，并提供手工备份与跨机器恢复。

首次技术闭环只支持手工录入和可提取文本的 PDF；当前增量已增加用户逐次确认的香港储蓄/年金公开研究。图片 OCR、表格文件、养老计算、提醒、其他市场主动研究和批量导出仍后置。

## 完整 V1 核心用例

### 家庭保障总览

用户可以看到成员、保单数量、年度保费、即将到期事项、保障分类和待核实问题。总览必须区分长期核心保障、依赖雇佣关系的团险、赠险和未知记录。

### 保单档案

用户可以手工建立或从资料中提取保单。每份保单包括产品版本、投保/被保险角色、期间、责任、免赔、赔付比例、`RenewalTerms`、`PremiumRate`、`RateAdjustmentRule`、实际缴费、医院/地区限制和来源证据。涉及身份信息的字段默认最小化或脱敏。

### 产品研究库

当前产品研究主入口是香港储蓄保险与年金，首批覆盖友邦、保诚、宏利。系统可通过 Codex CLI 实时网页搜索发现全网线索，但只抓取预置官方域名；证据摘录逐字匹配后生成待核验字段，人工完成必需身份字段核验后才可进入正式比较。内地、宠物险和其他市场收纳到“规划中”。

### 导入与核验

导入流程必须先预览文件、计算哈希、提取文本，再生成候选字段。用户逐项接受、修改或拒绝，系统记录提取器版本和核验时间。重复文件按内容哈希识别，不重复创建事实。首次交付只处理可提取文本的 PDF；扫描件保持“暂不支持”，不得静默尝试云端 OCR。

### 对比工作台

用户先定义比较案例，再选择产品。系统检查年龄、地区、币种、预算、缴费、领取/保障期间和版本是否一致；不一致项突出显示。表格始终把合同保证、非保证演示、费用、限制和证据状态分开。

### 养老规划

用户用本地参数建立多个方案：缴费计划、领取起点、领取频率、保证期间、寿命情景、现金价值、身故利益、币种和汇率。所有输入、公式和结果可导出并复算。

### 复盘提醒

用户可以按生效日、终止日、续保节点和自定义月份建立复盘任务。提醒只在本地运行；不自动续费或修改保单。

### Codex 研究助手

用户在对比页或证据页主动点击后，先查看即将发送的脱敏材料，再调用 Codex CLI。返回内容标记为 AI 草稿，并附引用的本地证据 ID、未知项和免责声明。

## 非功能需求

- Windows 11 为首要验收环境；Windows 10 仅在依赖仍支持时尽力兼容。
- 无网络时可查看和编辑档案、证据、比较案例并运行确定性计算。
- 常规列表操作在本地合成的 10,000 条产品记录下保持可用响应。
- 应用异常退出后不产生半写入事实；数据库迁移前自动生成可恢复备份。
- 所有高敏感文件路径、AI 调用和导出动作有明确用户提示。
- 默认无遥测、无广告、无后台云同步。

## 宠物险 V1 维度

宠物险不是完整 V1 的占位模块，但不进入首次交付。后续 V1 至少支持宠物种类/品种、年龄、芯片或免疫要求、等待期、既往症、指定医院、年度限额、单次限额、免赔额、赔付比例、药品/手术/检查范围、第三者责任、续保和费率变化。品种或疾病限制必须能绑定证据。

## 结果表达

系统不输出单一“最好产品”。允许输出“在当前假设下的差异”“保证现金流更高”“限制更多”“证据不足”等描述，并把主观权重与客观事实分开展示。
