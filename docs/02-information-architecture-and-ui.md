# 信息架构与 UI

## 视觉基线

V1 采用已经确认的蓝白 Apple 风格：大面积留白、克制的蓝色强调、清晰的数字层级、低噪声卡片、轻边框和高可读性状态标签。视觉精致不能牺牲证据、未知项和风险提示的可见性。

设计令牌建议：

- 主色：`#1677FF`；深色文字：`#162033`；次级文字：`#667085`。
- 页面背景：`#F5F8FC`；卡片背景：`#FFFFFF`；边框：`#E6ECF3`。
- 成功、警告、冲突、过期分别使用绿、琥珀、红、灰蓝，并同时配文字/图标，不能只靠颜色。
- 正文最小 14px，关键数字 24–40px；圆角 12–20px；交互焦点始终可见。

## 导航

一级导航：总览、家庭保单、内地产品、香港产品、宠物险、对比工作台、养老规划、来源中心、复盘提醒、更多险种、设置。

任何页面都能打开全局“待核实”抽屉，查看未知、冲突、已过期和 AI 草稿。

## 关键状态组件

- `VerifiedBadge`：已人工核验，显示核验时间和来源等级。
- `UnknownBadge`：尚无足够证据，禁止被摘要成确定事实。
- `ConflictBadge`：两个或更多来源不一致，可打开差异视图。
- `StaleBadge`：超过复查期限或发现更新版本。
- `EstimatedBadge`：计算或手工假设，显示公式/假设。
- `AiDraftBadge`：Codex 生成，等待人工接受；永不等同已核验。

## 可访问性与空状态

- 键盘可完成导航、筛选、对比和核验。
- 图表同时提供数据表和文字摘要。
- 金额始终显示币种，日期使用明确地区格式。
- 空产品库应引导导入官方资料，不用虚构品牌或保费填满页面。
- 占位页明确写“尚未实现”，不能让用户误以为已覆盖相应险种。

## 响应式范围

首版按 1280×800 及以上 Windows 桌面优化；1024px 宽度保证核心功能可用。暂不承诺手机端，但布局组件避免把业务逻辑绑定到固定像素。
