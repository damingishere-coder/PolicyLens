# 来源、证据与导入

## 来源权威性

`SourceAuthority` 只表示证据本身的权威程度，不表示值如何提取，也不表示是否已经人工核验。

| SourceAuthority | 来源 | 可支持的用途 |
|---|---|---|
| `CONTRACT_DOCUMENT` | 正式保险条款、正式保单、正式利益演示书 | 经人工核验后支持合同事实 |
| `REGULATOR_PUBLICATION` | 监管机构正式披露或公告 | 支持监管、主体和公开规则事实 |
| `INSURER_OFFICIAL_DISCLOSURE` | 保险公司正式公告、费率或服务文件 | 支持产品状态、费率及服务事实 |
| `INSURER_OFFICIAL_WEB` | 保险公司官方产品页 | 支持辅助事实，必须记录获取日期和版本 |
| `THIRD_PARTY_REFERENCE` | 第三方平台、媒体、社区、搜索摘要 | 只作为寻找官方来源的线索 |
| `UNATTRIBUTED` | 无法确认发行者或出处 | 不支持已核验产品事实 |

用户上传、网页下载或本地扫描属于获取渠道，不改变 `SourceAuthority`。OCR、规则和 AI 属于 `ValueOrigin` 或提取过程，不是来源权威性。权威性高也不代表永不过期；条款版本、销售地区和生效日期必须同时匹配。

## 导入流水线

1. **选择与预检**：用户选择本地文件；检查类型、大小、可读性和是否包含密码保护。
2. **建立指纹**：流式计算 SHA-256，检测重复或已存在版本。
3. **安全复制**：原文件复制到私有 vault；数据库只保存 vault ID，不在日志打印原路径。
4. **本地解析**：首次交付只读取可提取文本；无文本页明确提示暂不支持。后续 V1 才允许进入可选本地 OCR。
5. **文档分类**：识别条款、计划书、利益演示、保单或一般材料，输出置信度。
6. **候选抽取**：生成字段值、单位、页码/坐标、原文片段、`ValueOrigin` 和提取器版本。
7. **规则检查**：检查共享限额、保证/非保证、币种、日期、合计关系、冲突，以及 `RenewalTerms`、`PremiumRate`、`RateAdjustmentRule` 之间是否自洽。
8. **人工核验**：用户接受、修改、拒绝或保持未核验；核验动作只改变 `VerificationStatus`，不能改写 `ValueOrigin` 或 `SourceAuthority`。
9. **发布版本**：已核验事实进入可比较版本；候选值保留在草稿层。

## 证据锚点

每个可比较字段至少能打开一个锚点。PDF 使用页码加坐标/片段；网页使用规范 URL、获取时间、页面标题、内容片段及快照哈希；表格使用工作表、单元格区域和原值。

为尊重版权，公开仓库和公开导出不保存完整第三方条款副本。私人 vault 中的合法个人资料仅供本地研究；报告默认引用短片段和定位，不复制整份材料。

## 核验状态流转

```text
UNVERIFIED ──人工核验+有效非 AI 证据──> VERIFIED
     │                              │
     ├──来源不一致──> CONFLICTING <─┤ 新来源冲突
     └──明确拒绝──> REJECTED          └──版本过期──> STALE
```

`STALE` 和 `CONFLICTING` 不能自动回到 `VERIFIED`。用户必须选择正确版本或补充来源。假设和计算不再作为核验状态：分别使用 `USER_ASSUMPTION` 与 `DETERMINISTIC_CALCULATION` 的 `ValueOrigin`。

## 官网信息收集

- 当前香港储蓄/年金研究采用低频、用户逐次确认的公开搜索与官方页面检查，不做后台高频爬虫。
- 全网结果只用于发现线索；产品事实只允许来自预置保险公司官方 HTTPS 域名，并需通过本地抓取和证据摘录匹配。
- 访问前检查网站条款、robots、公开 API 和频率限制。
- 不登录、不绕过验证码/WAF、不模拟购买、不抓取个人账户页面。
- 使用明确 User-Agent、限速、指数退避和缓存；失败不无限重试。
- 网页变更只产生“待复核版本”，不能静默覆盖既有事实。

## 冲突示例

若产品页写“最高可达某金额”，而条款定义多个共享责任限额，系统同时保留两条来源，将产品页标为营销表述、条款标为合同口径，并要求用户核对共享关系。UI 不得把所有子责任简单相加。

## 过期规则

来源可按类别配置复查周期；停售公告、费率表和官方网页应比稳定条款更频繁复查。复查失败表示“本次无法确认”，不等同来源已经失效。
