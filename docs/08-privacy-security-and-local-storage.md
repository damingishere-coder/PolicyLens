# 隐私、安全与本地存储

## 威胁模型

主要风险包括：误把私人文件提交到公开 GitHub；其他 Windows 用户读取数据目录；恶意 PDF/网页内容利用解析器；Renderer 获得过大系统权限；本地端口被其他进程调用；日志/备份/导出泄露；AI 调用发送过多资料。

V1 不声称防御已控制当前 Windows 账户的高级攻击者。系统安全依赖 Windows 账户、设备磁盘加密和及时更新，同时通过最小权限与数据最小化减少影响。

## 数据分类

| 级别 | 示例 | 默认处理 |
|---|---|---|
| Public | 源代码、公开产品链接、合成 fixture | 可进入 GitHub |
| Internal | 本地设置、无个人关联的研究笔记 | 本地保存，导出前复查 |
| Sensitive | 家庭关系、保单元数据、财务目标、宠物健康情况 | 加密字段、禁止遥测和 GitHub |
| Restricted | 原始保单、证件/联系方式、详细健康资料、密钥 | 私有 vault、最小采集、默认不进 AI |

## 存储设计

- 默认数据目录位于 Windows 当前用户的应用数据目录，使用仅当前用户可访问的 ACL。
- 研究数据库与家庭数据库分离；高敏感值在应用层使用 AES-GCM 等认证加密。
- 随机数据密钥由 Windows DPAPI 保护，不把密钥写入仓库、日志或导出。
- 原始文件按内容哈希存入加密 vault；数据库保存逻辑 ID，不依赖原始绝对路径。
- 锁定应用或退出后清除内存中的解密密钥和临时明文。

加密实现必须使用成熟库和独立 nonce，不自创密码算法。若某平台依赖无法可靠打包，加密功能不得以“已保护”名义降级；应用应阻止导入或明确要求用户确认风险。

## GitHub 防泄漏

- `.gitignore` 排除家庭数据目录、数据库、原始资料、备份、导出、日志、密钥和工作文件。
- 提交前执行敏感路径、密钥模式、个人标识和大文件扫描。
- 测试只使用明显标记为 synthetic 的虚构人员、机构、保单号和金额。
- CI 不上传数据库、截图、失败日志或测试报告中的私人数据。
- 一旦发现误提交，停止 push；若已公开，按泄漏事件处理，不能只删除最新文件假装历史中不存在。

## AI 数据外发

Codex 分析是可选联网处理，不等同离线计算。每次调用前显示发送预览和字段类别；默认删除直接身份标识、私人路径和无关健康描述。用户取消时不发送。调用审计只保存哈希和结构化元数据。

## 文件与解析安全

- 只接受 allowlist 类型，校验文件签名而非只看扩展名。
- 设置单文件、页数、解压后大小和解析时间上限，防止压缩炸弹和资源耗尽。
- PDF/OCR 解析在低权限 sidecar/子进程中运行，依赖及时更新。
- 不执行附件脚本、宏、嵌入文件或外部链接。
- 网页快照按不可信内容处理，不能影响系统提示或启动本地命令。

## 本地 API 与桌面

- 只监听 loopback 随机端口，每次启动使用短生命周期令牌。
- Renderer 使用严格 CSP，不加载任意远程脚本。
- 外部链接通过确认后交给系统浏览器；不在特权窗口中直接打开。
- IPC 和 API 都使用明确 Schema，拒绝额外字段与路径穿越。
- 日志采用字段 allowlist，默认不记录请求体、证据原文和绝对私人路径。

## 导出与删除

导出默认先预览敏感字段，文件名不包含成员姓名。私人报告保存到用户选择的位置，并显示“该文件已离开受保护数据目录”。删除先进入本地回收/隔离状态；永久删除必须明确确认，并说明备份可能仍包含副本。

## 安全验收门槛

- 能证明私人档案、数据库、vault 和导出不在 Git 跟踪列表。
- Renderer 无 Node 全局对象，无法调用任意 shell。
- loopback API 缺少或伪造令牌时拒绝请求。
- 日志、崩溃和 AI 失败场景中无敏感正文。
- 备份可恢复且没有明文临时副本残留。
