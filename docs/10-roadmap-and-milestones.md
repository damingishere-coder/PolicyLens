# 路线图与里程碑

## 阶段原则

每个阶段都应形成可运行、可测试、可回滚的本地增量。先建立隐私和证据底座，再增加数据量和 AI 能力；不以爬取数量替代正确性。

## M0：文档与仓库基线

- 确认本套开发文档。
- 初始化默认分支保护、Squash-only、自动删分支、PR 模板和基础 CI。
- 确认本项目许可证选择。
- 建立隐私扫描和纯合成测试数据规则。

验收：文档无真实家庭资料；任务分支、PR 和 CI 工作流可用。

## M1：Windows 工程骨架

- Electron/React、FastAPI sidecar、共享契约和 SQLite 迁移。
- 蓝白设计令牌、导航、错误边界和基础可访问性。
- loopback 令牌、进程生命周期、数据目录与设置页。
- Dashboard、保单档案、来源中心基础 CRUD。

验收：开发/打包版本都能启动和退出；无残留端口；离线 CRUD 可用。

## M2：导入与证据闭环

- PDF/图片/表格/手工导入、哈希去重、本地文本提取。
- 候选字段、原文定位、人工核验、冲突和版本历史。
- 私有 vault、日志脱敏、加密和恢复模式。

验收：合成资料可从导入走到字段级证据；未经核验不能发布为事实。

## M3：三类产品库

- 内地产品适配器和筛选。
- 香港产品的币种、保证/非保证和跨境提示字段。
- 宠物、宠物险条件和专用比较维度。
- 车险、企业险等更多险种占位页。

验收：三类产品库使用同一证据规则；占位页无虚构产品或伪功能。

## M4：比较与养老计算

- ComparisonCase、资格检查和不可比提示。
- 保证/非保证分栏、XIRR、回本、寿命和汇率情景。
- 数据表、图表、公式说明及 Markdown/CSV/打印导出。

验收：黄金样例、边界条件和独立复算通过；AI 不参与数值计算。

## M5：Codex 研究助手

- 脱敏预览、固定参数 allowlist、隔离目录和结构化输出。
- 证据引用检查、未知项、草稿接受流程和失败降级。
- 缺失 CLI、未登录、断网、取消、超时、非法输出的测试。

验收：Codex 失败不改事实、不影响确定性结果；无敏感材料进入日志或测试产物。

## M6：复盘、备份与 Windows 发布

- 本地提醒、年度复盘清单、版本过期检查。
- 加密备份、恢复演练、诊断包和数据迁移。
- Windows 安装包、签名规划、升级/卸载保留数据策略。

验收：干净 Windows 环境安装冒烟通过；备份能恢复；卸载默认不删除家庭数据。

## V1 后续

- 车险、企业险、责任险等专用模型。
- 经合规评估的更多官方数据适配器。
- 多设备或家庭共享；只有在端到端加密、权限和冲突模型成熟后评估。
- 移动端和浏览器扩展不纳入 V1 承诺。

## 发布门槛

任何“V1 完成”声明都必须同时满足功能、隐私、恢复、安装包和真实本地运行验收。单元测试通过或页面能打开都不足以单独宣布完成。
