# 路线图与里程碑

## 阶段原则

完整 V1 保留既定产品逻辑，但拆成多个可运行、可测试、可回滚的本地增量。首次交付只建立最小闭环，不以页面数量、爬取数量或功能占位数量衡量完成度。

## M0：文档与本地基线

- 确认 V1.1 开发文档、14 页视觉和首次交付边界。
- 建立隐私扫描、纯合成测试数据和依赖许可证规则。
- 明确首次开发只修改本地项目；未经用户后续明确要求，不执行 GitHub Push、PR 或合并。

验收：文档无真实家庭资料，首次交付与完整 V1 的范围没有混用。

## M1：首次可用交付——核心闭环 + Codex 草稿

- React/Vite 浏览器前端、FastAPI 同源 localhost 服务、共享契约、SQLite 迁移和 RunDock 托管。
- 最小 Dashboard、保单档案、保单详情、产品证据详情、来源中心、设置与隐私。
- 手工录入和文本型 PDF 导入、哈希去重、候选字段、人工核验和版本历史。
- 两个本地产品版本的基础字段比较，不包含 XIRR、养老或汇率模型。
- `VerificationStatus`、`ValueOrigin`、`SourceAuthority` 三维数据语义。
- `RenewalTerms`、`PremiumRate`、`RateAdjustmentRule` 和实际保费记录。
- 本机 DPAPI 解锁、恢复密码便携备份及另一台 Windows 电脑恢复。
- Codex 白名单载荷、逐次外发预览、结构化草稿和失败降级。
- 其余确认页面提供清楚的可点击空状态。

验收：通过 RunDock 托管的 localhost 页面完成“导入两份合成资料 → 人工核验 → 查看证据 → 基础比较 → Codex 草稿 → 加密备份 → 跨机器恢复”的完整闭环；服务 PID、监听端口、健康状态和托管关系均可核验。

## M2：确定性计算与养老规划

- ComparisonCase 资格检查和不可比提示。
- 保证/非保证分栏、XIRR、回本、寿命和汇率情景。
- Retirement Planner 的数据表、图表和公式说明。

验收：黄金样例、边界条件和独立复算通过；AI 不参与数值计算。

## M3：三类完整产品库

- 内地产品适配字段、筛选和版本管理。
- 香港产品的币种、保证/非保证和跨境提示。
- 宠物档案、宠物险条件和专用比较维度。
- 车险、企业险等继续保持明确占位。

验收：三类产品库使用同一证据与版本规则；占位页无虚构产品或伪功能。

## M4：资料能力与复盘

- 本地图片 OCR、表格导入和低频用户触发的官方页面更新。
- 本地提醒、年度复盘、来源过期检查。
- Markdown、CSV、打印报告和诊断包导出。

验收：OCR/网页内容不直接升级为事实；提醒和导出均无后台云同步或隐私泄漏。

## M5：完整 V1 加固

- 性能、可访问性、迁移、备份恢复和 RunDock 重启回归。
- 依赖许可证、漏洞、日志、诊断包和敏感信息审计。
- 干净 Windows 环境的运行依赖配置、RunDock 登记和恢复验收。

验收：功能、隐私、恢复、RunDock 托管和真实本地运行全部通过，才能声明完整 V1 完成。

## V1 之后

- 车险、企业险、责任险等专用模型。
- 经合规评估的更多官方数据适配器。
- 多设备或家庭共享；只有在端到端加密、权限和冲突模型成熟后评估。
- 移动端和浏览器扩展不纳入 V1 承诺；localhost 浏览器页面不等同于公网 Web 服务。
