# 测试与验收

## 测试层次

### 单元测试

- 金额、比例、日期、币种和枚举校验。
- XIRR、回本、现金价值、保证领取、寿命和汇率情景。
- 共享限额、互斥利益和不可比条件规则。
- 证据状态流转和版本替代。
- 路径、文件类型、大小和日志脱敏函数。

### 契约测试

- OpenAPI 与生成的 TypeScript 类型无漂移。
- 金额以十进制字符串传输，未知字段被拒绝。
- Renderer → preload → main → sidecar 的错误映射稳定。
- Codex 输出必须通过 JSON Schema 并引用存在的证据 ID。

### 集成测试

- 合成 PDF 导入、哈希去重、候选字段、人工核验和发布版本。
- 来源更新造成冲突/过期，不覆盖历史事实。
- 比较案例固定产品版本，更新后旧结果仍可复算。
- 数据库迁移失败时恢复备份并进入只读模式。

### 桌面端到端与冒烟

- 14 个页面的导航、加载、空状态、键盘和错误状态。
- 本地 API 使用随机 loopback 端口和令牌。
- 打开/关闭应用后检查 sidecar 和端口状态。
- 打包安装、升级、卸载与数据保留。
- 屏幕宽度、缩放 100%/125%/150% 和高对比度基础检查。

### 安全与隐私测试

- Git 跟踪、构建产物、日志、诊断包、备份和 AI 输入扫描。
- 路径穿越、恶意文件名、超大/损坏 PDF、压缩炸弹和解析超时。
- Renderer 无任意 Node/shell 权限；CSP 和外部链接策略生效。
- API 缺少/错误令牌、非 loopback Origin 和超大请求被拒绝。
- 提示注入样例不能触发命令、外部动作或事实升级。

## 合成数据要求

fixture 使用明显虚构的姓名、机构、产品、保单号、地址和金额，不以真实档案“改一两个数字”方式脱敏。文件元数据、截图和测试失败输出也必须检查。

## 确定性计算黄金样例

至少覆盖：等间隔/不等间隔现金流、闰年、同日多笔现金流、无正负组合、无解、多重符号变化、极低/极高利率、不同币种小数位、领取与现金价值互斥、分红为零、汇率三情景。

每个黄金样例保存人工推导或独立实现结果、容差和公式版本。依赖库升级后必须重跑并审查差异。

## 页面验收重点

- Dashboard 同时显示已核验、未知、冲突和过期数量。
- 保单详情不把多个共享责任限额简单相加。
- 内地/HK 页面始终显示司法辖区、币种、条款版本和来源。
- 宠物险显示品种/既往情况、等待期、医院、免赔、限额和续保限制。
- 更多险种页面明确为占位，不出现可误解为真实的产品列表。
- 导入页要求人工逐项确认，OCR 置信度不替代核验状态。
- 比较页先显示保证和非保证为零情景，再显示演示情景。
- 养老页展示公式、输入和互斥情景，不只展示单一回报百分比。
- Codex 输出始终有 `AI 草稿` 标签、证据引用和未知项。
- 设置页能查看真实数据目录、备份状态和 AI 发送预览规则。

## CI 门槛

每个 PR 至少执行格式检查、lint、类型检查、前后端单元测试、契约测试、迁移测试、依赖许可扫描、秘密/私有路径扫描和构建冒烟。Windows 专属打包/进程测试在 Windows runner 上执行。

## 人工验收

自动化测试通过后，项目所有者在真实 Windows 环境使用合成资料完成一次导入、核验、比较、养老测算、Codex 失败降级、备份和恢复。只有人工确认 UI 与边界均符合预期后，才允许 Squash 合并。
