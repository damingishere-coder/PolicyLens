# 测试与验收

## 测试层次

### 单元测试

- 金额、比例、日期、币种和枚举校验。
- `VerificationStatus`、`ValueOrigin`、`SourceAuthority` 的独立组合与状态流转。
- `RenewalTerms`、`PremiumRate`、`RateAdjustmentRule` 和实际保费记录的版本与关联规则。
- 共享限额、互斥利益和不可比条件规则。
- 路径、文件类型、大小和日志脱敏函数。
- 后续 V1 增加 XIRR、回本、现金价值、保证领取、寿命和汇率情景。

### 契约测试

- OpenAPI 与生成的 TypeScript 类型无漂移。
- 金额以十进制字符串传输，未知字段被拒绝。
- 浏览器 API 客户端 → FastAPI → 领域服务的错误映射稳定。
- Codex 输出必须通过 JSON Schema 并引用存在的证据 ID。
- Codex 输入 DTO 只允许白名单字段，拒绝文件路径、vault ID、完整原文和未知字段。

### 集成测试

- 合成文本型 PDF 导入、哈希去重、候选字段、人工核验和发布版本。
- 来源更新造成冲突/过期，不覆盖历史事实。
- 比较案例固定产品版本，更新后旧结果仍可复算。
- 数据库迁移失败时恢复备份并进入只读模式。
- DPAPI 本机解锁与恢复密码跨机器恢复使用不同密钥包装；新电脑恢复后重新生成本机 DPAPI 包装。

### 浏览器端到端与 RunDock 冒烟

- 14 个页面的导航、加载、键盘和错误状态；首次交付未启用页面必须显示明确空状态。
- 页面与 API 使用 RunDock 指定的同一 loopback 端口；会话 Cookie、Origin 和 CSRF 校验生效。
- 检查 RunDock 进程记录、实际监听 PID、父进程链、健康端点、自动重启配置和数据目录。
- 浏览器上传 PDF/恢复包及下载加密备份，不允许客户端提交服务端绝对路径。
- 屏幕宽度、缩放 100%/125%/150% 和高对比度基础检查。

### 安全与隐私测试

- Git 跟踪、构建产物、日志、诊断包、备份和 AI 输入扫描。
- 路径穿越、恶意文件名、超大/损坏 PDF、压缩炸弹和解析超时。
- 浏览器页面无任意 Node/shell 权限；CSP 和外部链接策略生效。
- API 缺少/错误会话或 CSRF、非同源 Origin 和超大请求被拒绝。
- 提示注入样例不能触发命令、外部动作或事实升级。
- Codex 外发载荷不含真实姓名、私人路径、原始文件、完整保单号、vault ID 或超限片段。
- 文档与 UI 不把一次性工作目录或只读沙箱描述为 Codex 的保密边界。
- 正确恢复密码可在另一测试机恢复；错误密码、篡改备份和版本不兼容在修改当前数据前失败。

## 合成数据要求

fixture 使用明显虚构的姓名、机构、产品、保单号、地址和金额，不以真实档案“改一两个数字”方式脱敏。文件元数据、截图和测试失败输出也必须检查。

## 后续 V1 确定性计算黄金样例

至少覆盖：等间隔/不等间隔现金流、闰年、同日多笔现金流、无正负组合、无解、多重符号变化、极低/极高利率、不同币种小数位、领取与现金价值互斥、分红为零、汇率三情景。

每个黄金样例保存人工推导或独立实现结果、容差和公式版本。依赖库升级后必须重跑并审查差异。

## 页面验收重点

- 研究首页显示三家公司、研究运行、待核验产品和最近运行摘要。
- 保单详情不把多个共享责任限额简单相加，并分开展示续保条款、费率版本和调费规则。
- 香港储蓄/年金页提供研究预览、逐次确认、运行状态、官方候选和本地产品档案；内地/宠物/其他险种统一收纳到“规划中”。
- 更多险种页面明确为占位，不出现可误解为真实的产品列表。
- 导入页要求人工逐项确认；扫描 PDF 明确提示暂不支持，不调用云端 OCR。
- 证据比较页允许 2–4 个已核验产品并展示保证属性、三维状态和证据数量；只有两个产品时保留 Codex 比较草稿能力。
- 养老页与提醒页首次显示后续 V1 空状态。
- Codex 输出始终有 `AI 草稿` 标签、证据引用和未知项。
- 设置页能查看真实数据目录、恢复密码备份状态和 AI 外发预览规则。

## CI 门槛

每次交付至少执行格式检查、lint、类型检查、前后端单元测试、契约测试、迁移测试、依赖许可扫描、秘密/私有路径扫描和浏览器构建冒烟。Windows 专属 RunDock 进程、端口、DPAPI 和跨机器恢复测试在 Windows 环境执行。若未来接入 CI，使用相同门槛。

## 人工验收

自动化测试通过后，项目所有者在真实 Windows 环境通过 localhost 页面，使用合成资料完成一次文本 PDF 导入、核验、证据查看、两产品比较、Codex 成功/失败、手工备份和跨机器恢复，并核对 RunDock 状态。养老测算、提醒和完整产品库不属于首次交付验收。
