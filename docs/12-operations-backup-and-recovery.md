# 运行、备份与恢复

## 数据目录

应用首次启动显示并创建本地数据目录，不把数据写入安装目录或 Git 工作区。建议结构：

```text
PolicyLens/
  databases/
  vault/
  backups/
  exports/
  logs/
  temp/
```

设置页展示每个目录用途和占用空间。路径变更采用复制、校验、切换三阶段流程；失败时继续使用原目录。

## 日志

- 默认 INFO，轮转并限制保留天数和总大小。
- 只记录事件 ID、模块、耗时、错误类别和脱敏路径标识。
- 不记录请求体、证据原文、完整文件名、家庭字段、AI 提示、环境变量或认证信息。
- 用户导出诊断包前显示文件清单并再次运行敏感扫描。

## 备份

备份包包含数据库、vault 对象、Schema 版本和清单哈希，不包含应用程序。备份默认加密，并写入临时文件后原子替换；失败不能破坏上一份成功备份。

支持手工备份和本地定时提醒。V1 不默认上传 OneDrive、网盘或其他云服务。若用户把备份目录放入云同步位置，设置页明确提示数据将离开纯本地边界。

## 恢复

1. 读取备份清单并验证格式、版本和哈希。
2. 在独立临时目录解密和检查，不覆盖当前数据。
3. 显示将恢复的记录、来源和冲突摘要。
4. 为当前数据生成安全快照。
5. 切换恢复数据并运行完整性检查。
6. 失败则回到切换前快照，保留诊断事件。

恢复演练必须使用合成数据；测试“创建 → 备份 → 修改/删除 → 恢复 → 比对哈希”的完整闭环。

## 数据库迁移

每次迁移前检查磁盘空间并创建迁移备份。迁移脚本必须幂等或明确记录已执行版本。启动检测到未知的新版本数据库时不得降级写入，只能提示使用匹配版本。

## 崩溃恢复

导入和生成任务写入检查点；重启后区分可安全继续、可重新运行和必须人工复核的任务。未知远程状态（例如 Codex 进程异常终止）不能自动重试，以免重复发送材料。

## 更新与卸载

- 自动更新不是 V1 必须项；首版可提示下载新版本和校验值。
- 更新前验证签名/哈希、关闭 sidecar 并备份数据库。
- 卸载默认保留家庭数据，并明确显示数据目录。
- 删除家庭数据是独立的高风险操作，需要再次确认并说明备份副本。

## 最小恢复目标

只要用户保留一个可验证的加密备份和密码/Windows 密钥能力，就应能在干净安装中恢复家庭档案、来源、核验记录、比较案例和提醒。缓存、OCR 中间文件和 AI 临时事件不属于必须恢复数据。
