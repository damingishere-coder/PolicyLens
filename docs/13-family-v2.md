# 家庭工作区 V2：实现与验收边界

## 产品与入口

- `/` 只依赖本地家庭数据和单独加载的养老记录，展示已有保单、未知信息、待办和养老进度。研究失败不会阻断建档。
- `/family` 独立管理成员；昵称重复只提示，不自动合并。成员可有多份保单，也可暂无保单。
- `/policies/new` 仅名称即可保存草稿。产品核验只限制关联正式产品，不能阻挡已有保险建档。
- `/policies/:id` 分开展示个人记录、期间、缴费、特别约定、原件和公共产品依据。私有记录不被产品更新覆盖。
- `/compare` 保存比较目的、对象、年龄、原币预算和期间；`/compare/:id` 恢复不可变快照，产品改变时标记过期。完整证据矩阵、两个产品的受控 AI 比较保留。
- `/retirement/:id` 管理各成员的月度收支目标。每次保存保留输入和结果，`?snapshot=` 定位历史；复算检查算法、输入哈希与结果一致。
- `/library` 组织家庭 PDF、整理中的产品资料、来源原文和解读笔记；`/evidence-search` 保留本地产品、候选和来源搜索。
- `/research` 保留香港高级研究；`/tasks` 提供站内待办；`/settings` 保留安全会话、隐私、备份恢复与运行诊断。

## 语义约束

档案状态、事实核验状态、值来源和来源权威性独立。仅有草稿或日期不齐时，不显示保障有效。登记期间内也不表示一定获赔或保障充分。

缴费使用十进制定点金额；实缴金额与日期必须同时存在。统计按实缴日期或应缴日期归年、按原币分别汇总，不把应缴当实缴，不把不同责任限额相加。待缴提示描述登记差额，不声称保险公司已确认欠费。修改某期记录时填写本期累计实缴。

养老参数均为指定参考日期、指定同一币种的月度净收支。三个情景依次为用户标记的确定收入、加入用户估计、再加入非保证演示；用户标记不等于合同保证属性已核验。无收入需要明确确认；缺失输入不计算缺口。当前不预测投资收益、税费、寿命、通胀、退保价值或自动换汇。

## AI 边界

新上下文解读独立使用 `ExplanationPayload`，不接受客户端直接提交家庭 DTO：

- 保单：只构造关联已核验产品的字段与所选证据，每段最多 600 字、最多 12 段。摘录本身仍需用户检查是否含私人内容。
- 养老：只构造指定历史计算的币种、月度汇总和固定算法假设；引用哈希仅来自这个脱敏汇总，不来自成员 ID、名称或备注。
- 本地预览不会调用 AI；正式调用要求该预览的哈希和明确确认，15 分钟过期。每份预览只能调用一次；失败、取消、重启或恢复备份均不自动重发。
- 服务端再验证结构和证据／计算引用；结果先保存草稿，仅可接受为笔记，不更新原事实。
- 所有外发执行共享互斥门禁；取消归属保持独立。保留既有 Codex 提供商、模型、登录和认证方式。

## 前端与数据

`app` 负责装配和 URL 路由，`pages` 负责页面，`features` 负责成员、保单、缴费、待办、养老、研究、证据、导入、比较、AI 和备份；`services/http` 统一会话与 CSRF，家庭 API 类型复用 OpenAPI 生成类型。成员、保单、缴费、资料与养老修改使用版本检查，避免旧页面覆盖新记录。

新家庭表为 `family_documents`、`household_tasks`、`retirement_plans`、`retirement_snapshots`、`comparison_records`、`context_analysis_runs`。个人文本、计算输入结果、比较条件与解读记录使用现有 EnvelopeCipher 加密；PDF 复用加密 vault 和原文 SHA-256。

家庭迁移 `family_0001 → family_0002`、整体 schema 版本 3，研究库仍为 `research_0002`。迁移保留原有 ID、密文、外键和缴费，不按名字合并。旧 ACTIVE 且无期间的记录显示状态待确认。恢复支持旧 family_0001 备份并先迁移验证。

恢复取得运行排他门禁；后台 AI／研究或其他请求未结束时直接拒绝切换。新目录的密钥解包、数据库与加密字段验证成功后才清理回滚目录；任一步失败保留原密钥并恢复已移动目录。备份中的运行中解读与研究标记为中断失败，不启动任何重试。

## 验证与部署

后端验证覆盖草稿、关联、冲突、期间、十进制金额、多币种归年、待办、不可变快照、原文完整性、真正无文字层的合成图片 PDF、隐私白名单、外部引用、重复调用、旧库迁移、便携备份以及切换前后密钥故障回滚。

Chrome 验证使用独立临时库，创建两位成员和医疗／意外／惠民保，登记缴费、查看原件、保存养老目标并复算、预览和接受假 AI 笔记、刷新恢复，并检查 390px 布局。原有香港研究、官方来源、候选比较、产品比较、外发确认和备份恢复同时回归。自动化完成并不代替真实用户的“10 秒看懂首页”测试。

部署沿用已有 RunDock PolicyLens 项目和 127.0.0.1:8768，不另起服务。停止服务后备份数据库、vault、keys、原有静态资源及 Git 版本；更新默认分支与构建后启动同一项目。检查监听 PID/父进程、管理记录、schema、实际入口资源哈希和浏览器行为。需要回滚时停止项目，恢复成套原数据与原代码/资源，再启动并验收；禁止只回退应用而保留不兼容新库。
