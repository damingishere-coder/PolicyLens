## 实施边界

- 独立工作区 `PolicyLens-worktrees/family-v2`，不在开发过程中更新正式服务资源。
- 只使用合成资料做自动化与浏览器写入验收；真实家庭记录不进入源码、测试、日志或 AI 输入。
- 允许未知资料先建档，但不自动确认保单有效、实际缴费、条款核验或保障充足。
- 旧成员不按昵称自动合并；保留 ID 与关联，可由用户明确重新关联。
- 迁移前 SQLite 一致性备份，迁移后检查外键与完整性；回滚使用原版本及完整备份。
- OCR 不以临时联网识别替代；系统通知与复杂养老模型不属于本次基础闭环。
